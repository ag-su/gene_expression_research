## 논문
### [유전자 발현 데이터에서의 오토 인코더 사전 학습과 미세조정을 통한 유방암 분자적 아종 분류](https://www.dbpia.co.kr/journal/articleDetail?nodeId=NODE11705229)
유방암(Breast cancer)은 유방 조직에서 악성 종양이 발생하는 질병으로, 여성에게 가장 흔한 유형의 암이다. 유방암은 4종류의 분자적 아종(Molecular subtype)으로 나뉘는데, 유방암 아종에 따라 환자들의 치료법에 차이가 있으므로, 아종을 정확하게 분류해내는 것은 매우 중요하다. 본 연구에서는 모든 종류의 암 유전자 발현 데이터로 오토인코더(Autoencoder)를 사전 학습한 뒤, 인코더 층의 가중치를 유방암 아종 분류 모델의 초기 가중치로 사용하여 미세조정(Fine-tuning)하는 방법을 제안한다. 실험 결과, 제안하는 미세조정 모델은 동일한 구조에 무작위로 초기화한 가중치를 사용한 모델보다 분류 정확도가 높았다. 이를 통해 다양한 암 데이터에서 학습한 유전자 발현 특징이 유방암 아종 분류 성능 향상에 도움이 됨을 확인하였다
